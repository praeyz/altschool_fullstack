FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

No. You can shorten links without an account, but signing up lets you manage, customise and track all of your links in one place.

Are the shortened links permanent? Will they expire?

Shortened links do not expire by default. You can choose to set an expiry date for any link from your dashboard.

Are there any limitations on the number of URLs I can shorten?

The Basic plan includes unlimited URL shortening. Paid plans add advanced customisation and analytics.

Can I customize the shortened URLs to reflect my brand or content?

Yes. You can use custom aliases and, on paid plans, your own branded domain.

Can I track the performance of my shortened URLs?

Yes. Every link comes with analytics showing clicks, locations, devices and referrers.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

All links are scanned for spam and malicious content, and every link is served over HTTPS.

What is a QR code and what can it do?

A QR code is a scannable image that opens a link on a phone. Scissor lets you generate a QR code for any of your links.

Is there an API available for integrating the URL shortening service into my own applications or websites?

Yes. The Teams plan includes API access so you can shorten and manage links from your own applications.
